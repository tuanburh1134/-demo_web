# Dự án Trang Web Java Spring Boot Cơ Bản

## Hướng dẫn khởi chạy

1. Yêu cầu: Đã cài đặt **JDK 17** trở lên và **Maven**.
2. Giải nén file `.zip`.
3. Mở thư mục bằng IDE (IntelliJ IDEA, Eclipse, VS Code).
4. Chạy file `com.example.mywebsite.MyWebsiteApplication.java`.
5. Mở trình duyệt và truy cập: `http://localhost:8080`.
